# ATIC Glove Code

This repository contains the code and data supporting the ATIC glove study.

## Repository structure

- `01_Sensor_Characterization/`
  - Code and data for characterization of the hydrogel–Ecoflex tactile sensing unit, and result analysis
  - Related to Fig. 2

- `02_Spatial_Recognition/`
  - Code and data for spatial position discrimination and object recognition, and result analysis
  - Includes Scenario A , Scenario B and Scenario C
  - Related to Fig. 3

- `03_Sign_Language/`
  - Code and data for 46-word sign language recognition, Pearson correlation analysis, and word-baesd sentence-level recognition recognition, and sentence-level recognition on edge inference
  - Includes Scenario D and Scenario E
  - Related to Fig. 4 and Fig. 6

- `04_Object_Discrimination and _Physical_Inference/`
  - Code and data for 21-class object discrimination using the 40-channel baseline configuration, TCO & ISO Outputs results analysis,physical-property estimation including object weight prediction, and edge inference
  - Includes Scenario F 
  - Related to Fig. 5

- `05_Edge_computing_achievement/`
  - Code and data for Edge computing on STM32
  - Related to Fig. 5 and Fig. 6


## System requirements

- MATLAB R2022a
- Origin 2024
- Python 3.8
- Keil uVision5
- Vofa+
- PyCharm Community Edition 2023.3.2

## Code availability

The customized code used for data processing, Pearson correlation analysis, machine-learning analysis, edge inference, and figure generation is provided in this repository.

## Data

The datasets used for the corresponding analyses are organized within each task folder.
